# Travel Explorer

A multi-page responsive travel discovery website built with **HTML5**, **CSS3**, **Bootstrap 5**, **jQuery**, and **AOS** animations.

## Pages & Features

- **Home (`index.html`)** — Full-bleed hero section, highlights grid, and call-to-action.
- **Destinations (`destinations.html`)** — Dynamic card catalog with live search, alphabetical/rating sorting, and star ratings.
- **About (`about.html`)** — Overview with animated destination counter.
- **Contact (`contact.html`)** — Validated inquiry form with inline confirmation feedback.
- **Dark Mode** — Persistent light/dark theme toggle stored in `localStorage`.

## Run Locally

Open `index.html` directly in any modern browser, or serve it with a local static server:

```bash
python3 -m http.server 8080
```
